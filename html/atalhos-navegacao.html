⌨ Atalhos e Navegação

Caso não seja possível o uso do mouse, o portal pode ser navegado integralmente pelo teclado. Confira abaixo os atalhos disponíveis para cada navegador e a ordem de acesso pela tecla TAB.

ℹ Dica: Utilize a tecla TAB para avançar entre os elementos da página e Shift + TAB para retroceder. Pressione Enter ou Espaço para ativar botões e links.

⚡ Atalhos Principais

🔡

🔄

📄

🔍
